# Streifenhelfer iPhone

Verschlüsselte iPhone-Web-App, Inhaltsstand 0.3.0-dev.17 vom 02.11.2026.

Dieses öffentliche Repository enthält nur die allgemeine Startseite und verschlüsselte App-Dateien. Zugangsschlüssel, Klartextinhalte und interne Originalunterlagen sind nicht enthalten.

GitHub Pages: Branch main, Ordner / (root). Nach Aktivierung die HTTPS-Seite in Safari öffnen. Der Zugangsschlüssel wird getrennt privat bereitgestellt. Für Offlinebetrieb zuerst entsperren und die Offline-Speicherung ausdrücklich aktivieren; anschließend in Safari zum Home-Bildschirm hinzufügen.

Automatisierte Chromium-, Kryptografie- und Offlineprüfungen bestanden. Ein echter iPhone-/Safari-Gerätetest und eine dienstliche Freigabe stehen aus. Die Funknotiz ist in dieser iPhone-Fassung deaktiviert. Sitzungseinstellungen und Merkliste werden beim Sperren zurückgesetzt.
