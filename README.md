# Streifenhelfer iPhone

Verschlüsselte iPhone-Web-App 0.7, Inhaltsstand Android 0.3.0-dev.20 vom 02.11.2026. Die bestehende App-Adresse und der privat bereitgestellte Zugangsschlüssel bleiben gleich.

Kurze App-Wechsel verdecken den Inhalt und erhalten die geöffnete Sitzung im Arbeitsspeicher. Nach mindestens fünf Minuten im Hintergrund wird vor dem Wiederanzeigen erneut gesperrt. iOS kann Hintergrundskripte anhalten; eine garantierte Speicherlöschung exakt nach fünf Minuten wird nicht behauptet. Neuladen, Schließen und ausdrückliches Sperren beenden die Sitzung sofort.

Die Einrichtungshilfe erklärt das Speichern des Zugangs in Apple Passwörter und das anschließende automatische Ausfüllen. Safari entscheidet über Speichervorschläge; ein Vorschlag lässt sich nicht erzwingen. Face ID gehört gegebenenfalls zu Apples Autofill und ist keine eigene biometrische Anmeldung dieser Web-App. Die Web-App speichert den Schlüssel selbst nicht dauerhaft.

Dieses öffentliche Repository enthält ausschließlich die allgemeine Zugangsshell und verschlüsselte App-Dateien. Zugangsschlüssel, Klartextinhalte und interne Originalunterlagen sind nicht enthalten. GitHub Pages verwendet main und den Stammordner. Eine ausdrücklich gespeicherte Offlinekopie enthält nur Shell und verschlüsselte Daten; für die neue Version die Offlinekopie aktualisieren.

Automatisierte Chromium-, Kryptografie-, Sitzungs- und Offline-Updateprüfungen bestanden. Ein echter iPhone-/Safari-/Home-Bildschirm-/Autofill-Test bleibt offen. Keine fachliche oder dienstliche Freigabe. Die Funknotiz ist in dieser iPhone-Fassung deaktiviert.
